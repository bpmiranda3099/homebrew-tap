# Homebrew Tap

Homebrew formulae for [ai-usage-bar](https://github.com/bpmiranda3099/ai-usage-bar-macos).

```sh
brew install bpmiranda3099/tap/ai-usage-bar
brew services start ai-usage-bar
```

Requires macOS 26 or later. The formula builds from source and needs Xcode 26.
